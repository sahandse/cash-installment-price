== Description ==
Cash Installment Price adds a second installment price display to WooCommerce products based on a configurable percentage or fixed surcharge.

== Installation ==
1. Upload the cash-installment-price folder to /wp-content/plugins/
2. Activate the plugin.
3. Open WooCommerce > قیمت نقدی/اقساطی.
