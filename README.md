# قیمت نقدی و اقساطی ووکامرس

افزونه نمایش همزمان قیمت نقدی و قیمت اقساطی برای محصولات ووکامرس با رابط فارسی و مینیمال.

## ویژگی‌ها
- نمایش قیمت نقدی و اقساطی کنار هم
- تنظیم درصد یا مبلغ افزایش قیمت اقساطی
- امکان تنظیم سراسری
- امکان توسعه تنظیم اختصاصی برای هر محصول
- رابط فارسی و مینیمال
- سازگار با WooCommerce
